Patient Health Viewer

SMART on FHIR demo app for the Epic sandbox

What this app does

This app connects to Epic's FHIR R4 sandbox with a SMART on FHIR standalone launch. You sign in to Epic as a test patient, and the app shows that patient's data.

How it works

  • OAuth 2.0 authorization code flow with PKCE (S256)
  • Read-only patient scopes
  • Tokens stay on the server. The browser only gets a session cookie.
  • Demo project for the Epic sandbox. Not for real patient data.
